# Ma Collection

Petit site pour ranger ses **vinyles** et ses **CD**, avec barre de recherche et photos prises directement depuis le téléphone.

## Fichiers

- `index.html` : la page
- `style.css` : le design
- `script.js` : le fonctionnement (onglets, recherche, photos, stockage)

## Mettre en ligne avec GitHub Pages

1. Crée un dépôt GitHub (ex. `ma-collection`).
2. Envoie les 4 fichiers (`index.html`, `style.css`, `script.js`, `README.md`) à la racine du dépôt.
3. Va dans **Settings → Pages**, choisis « Deploy from a branch », branche `main`, dossier `/ (root)`, puis Save.
4. Le site sera disponible sur `https://TON-PSEUDO.github.io/ma-collection/`.

## À savoir

Les photos et les infos sont enregistrées dans le navigateur de l'appareil utilisé (IndexedDB), pas sur GitHub. La collection n'est donc pas partagée entre plusieurs appareils.
